# Log Parser Script (`parse.py`)

A simple Python script that parses C/C++ compiler or linter warning log files and exports them into a CSV format.

## Features

- **Regex Parsing:** Extracts the file path, line number, and full warning message from log entries.
- **Custom Output File:** The output CSV filename can be provided as a command-line argument.
- **Standard Library Only:** Uses built-in Python modules (`sys`, `re`, `csv`, `os`), so no extra package installation (`pip`) is needed.
- **Safety Checks:** Checks if the input log file exists or is empty before attempting to parse.
- **Simple Command-Line Usage:** Accepts the input log file and output CSV file as arguments.

## Prerequisites

- Python 3.x installed on your machine.

## How to Use

1. Save `parse.py` in your working directory.
2. Run the script by providing the input log file and output CSV file:

```
python3 parse.py <path_to_source.log> <output.csv>
```

### Example

```
python3 parse.py warnings.log warnings.csv
```

Or, if the log file is in another directory:

```
python3 parse.py ../warnings.log warnings.csv
```

The first argument is the **input log file**:

```
../warnings.log
```

The second argument is the **output CSV file**:

```
warnings.csv
```

## Output Format

The generated CSV file contains three columns:

```
Line,File,Message
```

Example:

```
Line,File,Message
123,src/example.cpp,warning: Something is wrong
456,src/test.cpp,warning: Another warning
```

## Error Handling

If the input file does not exist, the script displays:

```
Error: File 'warnings.log' not found.
```

If the input file is empty:

```
Warning: The file 'warnings.log' is empty. Nothing to parse.
```

If no matching warning entries are found:

```
No matching log entries were found.
```

## Jenkins Pipeline Usage

This script can also be used in a Jenkins Pipeline.

For example:

```
stage('Run Parser') {
    steps {
        dir('parser-repo') {
            sh '''
                python3 parse.py ../warnings.log warnings.csv
            '''
        }
    }
}
```

In this example:

```
../warnings.log
```

is the Doxygen warning log generated by the previous pipeline stage, and:

```
warnings.csv
```

is the output file generated by the parser.

The resulting workspace will look like:

```
workspace/
├── warnings.log
└── parser-repo/
    ├── parse.py
    └── warnings.csv
```
